# Higienize SC

Professional website project developed for an upholstery cleaning company based in Florianópolis, Brazil.

This project is being built using ASP.NET Core MVC with a modern responsive interface focused on performance, visual presentation, user experience, and mobile optimisation.

## Main Features

* Responsive and Mobile First layout
* Professional services presentation
* Dynamic testimonials section
* Persistent customer comment system
* SQLite database integration
* Entity Framework Core integration
* Dynamic testimonials with avatars and ratings
* FAQ section
* Animated service cards
* Responsive mobile navigation menu
* Mobile optimised hero section
* Online deployment for testing and preview

## Technologies Used

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQLite
* HTML5
* CSS3
* Razor Pages
* Bootstrap Icons
* Docker
* Render Hosting

## Project Status

Project currently under development.

Current implemented improvements:

* Persistent comment system using SQLite
* Database migrations with Entity Framework
* Customer city display in comments
* Mobile responsive improvements
* Dynamic testimonial cards
* Success message after comment submission

Future improvements planned:

* Admin panel
* Google authentication
* Comment approval system
* Dynamic gallery management
* Dashboard for comment moderation
